# Imon Hosen's Personal Website

This is the personal website for Imon Hosen, featuring a portfolio, blog, and admin system.

## Features

- Responsive design that works on all devices
- Dark theme with cyan accents
- Portfolio showcasing projects and skills
- Blog system with admin capabilities
- Image upload functionality for blog posts

## Blog System

The website includes a complete blog system with the following features:

### For Visitors
- Featured post section highlighting the newest blog post
- Grid layout of older blog posts
- Individual blog post pages with related posts
- Responsive design for all screen sizes

### For Admin
- Secure admin login (username: admin, password: password123)
- Add new blog posts with image uploads from device or URL
- Edit existing blog posts
- Delete blog posts
- New posts automatically appear as the featured post

## How to Use the Blog Admin System

1. Navigate to the blog page and click on "admin" in the navigation
2. Log in with the credentials:
   - Username: admin
   - Password: password123
3. In the admin dashboard, you can:
   - Add new blog posts with the form in the "Add New Blog" tab
   - Manage existing posts in the "Manage Blogs" tab
   - Upload images directly from your device or use image URLs
   - Edit or delete existing posts

### Adding a New Blog Post

1. Fill in the blog post details (title, category, etc.)
2. Add an image by either:
   - Uploading from your device using the file input
   - Entering an image URL in the text field
3. Write your blog content in the content field
4. Click "Publish Blog Post"

The newest blog post will automatically appear as the featured post on the blog page.

### Editing a Blog Post

1. Go to the "Manage Blogs" tab
2. Click the edit icon next to the post you want to modify
3. Update the post details in the modal that appears
4. Click "Update Blog Post"

Edited posts will move to the top of the blog list and become the featured post.

## Technical Details

The blog system uses:
- LocalStorage for data persistence
- JavaScript for dynamic content loading
- CSS for responsive design and animations
- FileReader API for image uploads
